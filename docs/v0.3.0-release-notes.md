# PREZEKC AI Framework v0.3.0 — Engineering Quality Candidate

> Proposed update package. Do not mark as a stable release until repository tests and real-project acceptance checks pass.

## Highlights

- **Clean Architecture & Safe Refactoring:** review responsibilities, dependencies, existing conventions, and behavior-preserving changes.
- **Modern Code:** verify framework/language versions before selecting APIs or libraries.
- **Clean Code:** require precise findings and pragmatic maintainability improvements, not aesthetic-only rewrites.
- **UI Design Quality:** preserve approved designs while checking visual hierarchy, component states, responsiveness and accessibility.
- **Defensive Security Review:** scoped, evidence-based checks with explicit limitations.
- **Quality Evidence Gate:** machine-readable, honest check reporting with `PASS`, `FAIL`, `NOT_RUN`, and `BLOCKED`.

## Compatibility

Preserves v0.2.0: P01–P09, PRD/SRS import-first, human approval, SDD, UI/UX Flow, Task Breakdown, 12 previous skills and the next-action protocol. Three additional skills bring the planned total to **15**.

## Not included

No autonomous exploitation tools, intrusive security scanning, 3D generation, mandatory external services, hardcoded 100/100 quality scores, or mandatory one-size-fits-all folder architecture.

## Verification before release

1. Apply using `--check`, then `--apply` after inspecting the preview.
2. Run the framework validator, all unit tests, and `git diff --check`.
3. Execute at least one web or mobile acceptance task using actual code, verify the evidence, and obtain owner release approval.

## Inspiration and reuse boundaries

Ideas were informed by the public project documentation for [anti-slop](https://github.com/miqdadbadjuber/anti-slop), [CyberStrike](https://github.com/CyberStrikeus/CyberStrike), and [mattpocock/skills](https://github.com/mattpocock/skills). No third-party code, templates, or text has been copied into this package; procedures were independently authored. This is not an endorsement or security certification.
