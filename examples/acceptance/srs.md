## Functional Requirements

### SRS-FR-001.1 — Period Selection

**Parent Requirements:** PRD-FR-001

**Statement:** The system shall allow an authorized reporting user to select an available reporting period.

### SRS-FR-001.2 — Record Retrieval

**Parent Requirements:** PRD-FR-001

**Statement:** The system shall return consolidated records corresponding to the selected reporting period to an authorized reporting user.

### SRS-FR-001.3 — Unauthorized Access

**Parent Requirements:** PRD-FR-001

**Statement:** The system shall deny consolidated-record retrieval to users without reporting access authorization.
